## Foam 003

- Source: https://ambientcg.com/a/Foam003
- Author: ambientCG
- License: CC0 1.0 Universal
- Download: `Foam003_1K-JPG.zip`, OpenGL normal map only
- SHA-256: `b3e5c7e31ae7aef3751c938a7dccd0c4e60caa92afc0d291088d0b1802d87076`

The ocean shader samples this normal map twice with different world-space
scales, directions, and scroll velocities. The source material is foam, but
its seamless micro-surface normals provide the irregular capillary detail
needed to break up smooth analytic wave reflections.
