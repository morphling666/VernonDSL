# Showcase assets

`rock/rock_boulder_cracked_packed_1k.png` packs the OpenGL normal map into RGB
and diffuse luminance into alpha. Its sources come from Poly Haven's
[Rock Boulder Cracked](https://polyhaven.com/a/rock_boulder_cracked) material
by Dario Barresi and Dimitrios Savva, released under CC0 1.0.

`noise512.png` comes from Kevin Roast's
[webglshaders](https://github.com/kevinroast/webglshaders) terrain demo and is
distributed under its MIT License, Copyright (c) 2015 Kevin Roast.

`terrain-showcase.webp` is a 48-frame VernonDSL render generated by
`terrain_showcase.py` for the repository README.

`mandelbulb-showcase.webp` and `fractal-showcase.webp` are DirectX renders
generated by their corresponding example scripts for the repository README.
