# Environment assets

## Belfast Sunset (Pure Sky)

- Source: https://polyhaven.com/a/belfast_sunset_puresky
- Authors: Dimitrios Savva, Greg Zaal, and Jarod Guest
- License: CC0 1.0 Universal
- Download: Poly Haven 1K HDR
- MD5: `38890f597727936a44d17a97f7f73354`

This partly cloudy, edited sky-only environment is the default. Removing nearby
terrain prevents land features from stretching across choppy water reflections,
while the cloud bands give those reflections visible structure. The example
converts the equirectangular HDR image to six tone-mapped cubemap faces at
startup. Attribution is not required by CC0, but the source and checksum are
retained for provenance and reproducibility.
