# VernonDSL reports

This directory contains reproducible measurements and historical baselines.
Reports are evidence, not normative contracts.

- `autodiff/`: autodiff smoke, memory-pressure, and comparison results.
- `benchmarks/`: focused performance measurements.
- `baselines/`: machine-specific regression baselines.

Each new report should record the workload, policy, platform, device,
driver/API, compiler contract, Program version, command used, and measurement
method.
